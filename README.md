# SafeSpeed UK — zone and camera data from OpenStreetMap

`uk_zones_seed.json` is a copy of the UK's average speed zones and fixed speed cameras in OpenStreetMap, as of its last refresh. `extras_db.json` (the "Extras DB") is the copy built into the SafeSpeed UK Android app, as it is there: made from the first, it only ever grows, and on the phone the app uses the zones and cameras in it that its own camera database hasn't got. Both are databases derived from [OpenStreetMap](https://www.openstreetmap.org), © OpenStreetMap contributors, and are published here under the [Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/), as the licence requires for a derived database. See [DATA_LICENSE.md](DATA_LICENSE.md) for the details and how the files are made.

The app itself is not open source; this repository holds only the data.
