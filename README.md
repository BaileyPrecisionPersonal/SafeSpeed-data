# SafeSpeed UK — zone and camera data from OpenStreetMap

`uk_zones_seed.json` is a copy of the UK's average speed zones and fixed speed cameras in OpenStreetMap. The SafeSpeed UK Android app takes from it the zones and cameras that its own camera database hasn't got. It is a database derived from [OpenStreetMap](https://www.openstreetmap.org), © OpenStreetMap contributors, and is published here under the [Open Database License (ODbL) v1.0](https://opendatacommons.org/licenses/odbl/1-0/), as the licence requires for a derived database. See [DATA_LICENSE.md](DATA_LICENSE.md) for the details and how the file is made.

The app itself is not open source; this repository holds only the data.
